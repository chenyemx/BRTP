The RSICD classification splits cover 10,000 of the original 10,921 images. MLRSNet uses one scene label per image. B2N trains separately on each dataset's base labels. For the main B2N results the test subset identifies which names compete. In the joint test all base and new names compete for each input. Primary CD trains on all 38 PatternNet classes (608 labeled images per fit). DG trains on the published shared-16 PatternNetv2 view (256 images per fit). Score all three target vocabularies using the final source checkpoint for a given seed. Source rotation repeats the same protocol with another training source. The original source's held-out test score is reported separately.

Support construction and model fitting
Within each source training class, use the archived sampling protocol identifier, task, source name, run seed and native class ID to permute eligible paths. Select the first K eligible source images after SHA-256 deduplication and rejection of validation or test matches. B2N checks the relevant native dataset, CD checks the four native datasets and DG checks the four v2 views. Target image hashes are used solely for this offline overlap check. Matched runs reuse the saved support rows. For a given seed and class, lower budgets are nested within higher budgets. Seeds 1–3 are used for primary comparisons. Seeds 1–10 are used only where indicated.

The main reference is the frozen OpenAI CLIP ViT-B/16 with four shared context tokens (2,048 trainable scalars) initialized from “a photo of a”. Train on all source support rows each epoch for 50 epochs. Use SGD with learning rate 0.002, momentum 0.9, weight decay 0.0005 and batch size 32. Cosine annealing reduces the learning rate to zero, with no warmup. Use source training labels only. The main result is the epoch-50 checkpoint. R = 0.25, b = 10, rho = 0.1 and lambda = 0.25 define Full. Earlier optimizer, initialization and radius explorations preceded this choice. The selection split and metric for every early choice are unavailable. Parameter sweeps hold the other reference choices fixed.

Convert to RGB. Training uses a random resized 224 × 224 crop (area 0.08–1, aspect ratio 3/4–4/3) with bicubic interpolation and a 0.5 horizontal-flip probability. For evaluation resize the shorter edge to 224 with bicubic interpolation and center-crop to 224 × 224. Both paths use CLIP channel normalization. Original runs used PyTorch 2.1.2, CUDA 11.8 and an RTX 3080 Ti. The encoders use mixed precision. The anchor geometry and the regularized kernel solve use FP32. The four local baselines use the common SGD schedule while retaining their model-specific objectives and heads. The PLKR run uses the archived torchsort boundary fix.

Summaries and comparison units
Compute image-level top-1 accuracy separately for each test vocabulary. For overall B2N, average Base and New across the four datasets with equal weight and across seeds, then compute H = 2 × Base × New / (Base + New). To report a dataset-specific H, pool that dataset's Base and New accuracies over seeds first. The mean of four dataset-specific H scores (80.51% for Full) differs from overall H (80.57%). For CD and DG, average the three target accuracies inside each seed and then across seeds. Use a sample SD (n − 1 denominator) on the per-seed scores. For H, each seed supplies its own harmonic score for the SD. Pair local comparisons on the same source draw. Seeds are repeated training on fixed test images. Published baseline results have different support identities and some different optimizer details. Differences in the manuscript are in percentage points. Primary estimates and contrasts before rounding are supplied in the accompanying evidence files. Values printed in source publications retain the source precision.
